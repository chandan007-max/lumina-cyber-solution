### 2. Primary Operator Feedback Items (From Guided Simulations)

1. **Receipt Slip Customization:**  
   *Observation:* Cyber café operators frequently want to add their UPI QR code directly on the printed thermal slip.  
   *Current Status:* Static UPI ID and QR code generator supported in receipt settings.
2. **Bulk Pricing for Document Services:**  
   *Observation:* Customers printing > 50 pages often receive volume discounts (e.g. ₹2/page instead of ₹3/page).  
   *Current Status:* Supported via line-item price override or discount field.
3. **Workstation Lock Screen Integration:**  
   *Observation:* Operators expressed strong interest in full Windows desktop locking when session timer expires.  
   *Current Status:* Application-level interface active; native OS desktop daemon scheduled for v1.1.
